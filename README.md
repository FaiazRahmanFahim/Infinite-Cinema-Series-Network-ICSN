# ICSN — Infinite Cinema & Series Network

**ICSN** is a modern, high-performance web application designed for discovering, exploring, and managing popular movies, TV series, and trending entertainment content.

---

## 🎬 Application Overview

ICSN delivers a premium, streaming-platform user experience with rich visual aesthetics, smooth micro-animations, dark/light mode support, and dynamic promise-based data loading.

- **Client App**: Located in `client/` built with React 19, Vite, React Router 7, Tailwind CSS v4, DaisyUI, Framer Motion, and Swiper.

---

## 🚀 Quick Start

```bash
# Navigate to the client application
cd client

# Install dependencies
npm install

# Start local development server
npm run dev
```

For full application documentation, features breakdown, and project structure, view [`client/README.md`](file:///e:/CODES/ICSN/client/README.md).
